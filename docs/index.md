## Project: SPORTSSTATS

**SPORTSSTATS** is a reproducible basketball statistics and probability forecasting platform built with Python, SQLite, a CLI, a JSON REST API, and an interactive web dashboard. It evaluates online logistic regression probability forecasts against historical threshold rates and constant baselines using Brier scores on FiveThirtyEight NBA regular-season data.

- **Selected Cloud Targets:** Multipass (local), Chameleon KVM@TACC (OpenStack), and Amazon EC2 / AWS (public cloud)
